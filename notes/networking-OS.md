# HTTP Guides
- a protocol for transmitting -> hypermedia (e.g., HTML)
- designed for comm between -> Web Browser (Client) & Web Server
- also used for comm between:
	- machine to machine (M2M) -> automatic system interaction (e.g., payment system - bank server via API/broker)
	- programmatic access -> fetching data via code (e.g., calling an API to render data in your own system)
- stateless -> the server does not manage or remember sessions between 2 separate requests
- stateful via extensions -> cookies/tokens are used to bring sessions into the picture
!HTTP Layers Diagram
- extensible protocol - evolved from transferring hypertext documents (HTML) to supporting images, videos, data submission to servers, and dynamic updates to parts of web pages.
